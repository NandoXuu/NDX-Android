# Example plugins

* `rust-support`   - declarative language plugin (no code runs)
* `solarized-theme`- declarative theme plugin
* `hello-commands` - code plugin (needs explicit approval + Settings > allow plugin code)

Install from the NDX console:  `ndx install /path/to/plugins/examples/rust-support`
Validate before publishing:    `python tools/validate_plugin.py plugins/examples/rust-support`
